# Streambox Kino

Streambox Kino is an Android multimedia app combining a media catalog, a local video player, IPTV playlists, internet radio and a built-in BitTorrent client.

**Interface language: Russian.**

## Features

- Movie, series and anime catalog with search, filters and favorites.
- Local and network media playback.
- Import of user-provided M3U/IPTV playlists.
- Internet radio and audio playback.
- Magnet links and .torrent files for downloads and supported video streaming.
- In-app update checks and an optional VPN module.

## Platforms

- **Android phones and tablets:** Android 10 or later.
- **Android TV:** a separate remote-control-friendly build is in development.

## Project status

This project is under active development. Features, provider availability and compatibility may change between releases. The repository currently contains project information and a place for feedback; the full Android application source is not published here.
